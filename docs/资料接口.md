# 资料服务接口

资料源支持单段 HTTP Range，返回 Content-Range 和内容摘要 ETag。If-Match 可以限定本次范围读取的来源版本，版本不符返回 412，越界返回 416。该行为只负责传输，不替接收应用决定领域对象是否完整。

本地子集服务实际执行轴标签、包含式采样范围与四个网格单元的单次上限；更新后的描述和返回网格一并改变版本、原点。数量相同不证明网格相容。

本地网关把 WCS DescribeCoverage 与覆盖响应规范化为保留轴、网格和版本的 JSON；并不声称 JSON 是所有 WCS 服务的必选格式。能力表规定切片和裁切支持，网格上下界为包含式整数索引，物理范围与网格索引必须区别。

本地服务的资料入口为 `/wcs/describe/park-temp`。`fixtures/ordinary.json` 记录当前可预览的资料；`fixtures/transition.json` 保存资料源连续两个发布日期。调用 `POST /control` 并传入 `{"action":"advance"}` 推进发布日期，`inspect` 返回实际请求记录，`reset` 恢复本地源；控制入口不属于远端标准协议。来源分段、延迟和断连均可用场景条目的 `chunks`、`delayMs`、`disconnect` 配置，不需要依赖实际网络故障。

原件目录采用内容摘要寻址，接收凭据独立记录来源、媒体类型和预览结果。单份资料接收不表示来源范围已经读完，也不推断缺失资料的业务含义。

## 按范围领取（子集收件）

`POST /subsets` 请求体为 `{"coverageId":"park-temp","trims":{"Lat":[下界,上界],"Long":[下界,上界],"time":[起,止]}}`。空间轴必须使用 DescribeCoverage 公布的轴标签与单位；物理值与网格索引分开处理，轴方向（Lat 降序、Long 升序）只影响索引不影响请求写法，KVP 一律按物理值从小到大给出。

收件流程固定为：先取 `/wcs/describe/<coverageId>` 与 `/wcs/capabilities`，理解轴名称、方向、单位、网格原点/步长、nil 值、可用格式与 `maxCells`，再规划实际请求。能力表未公布 trim、或公布格式中没有 `application/json` 时直接拒绝，不猜测其他协议。`sliceSupported=false` 的轴（time）不能精确裁切：请求中给出时间窗口只会进入凭据的说明部分，实际返回来源公布的整段时间，并列出多携带与超出公布时段的范围。

服务只做网格点包含式采样。需求区间包含网格点时取全部落入点；夹在网格点之间时向外对齐到包围需求的最近网格点，多取的物理区间写入 `axes[].overfetch`；需求越过覆盖公布范围的部分写入 `axes[].outsideCoverage`，不会悄悄缩小需求。完全没有重叠网格点的请求返回 422，不制造空网格。

大范围按 `maxCells` 拆成索引空间互不重叠的多块，逐块核对 coverageId、version、origin、offsets、shape、bounds、数值数量与 nil 标记；任一不符标记为 `grid-mismatch`，版本或原点变化标记为 `version-conflict` 并中止，已收下的旧网格保留但绝不与新网格拼接。合并时同一全局索引只算一次观测，重复且数值冲突直接报错。每块来源原件按内容摘要存入 `objects/`，子集凭据存入 `subsets/`，可用 `GET /subsets` 列表、`GET /subsets/<id>` 回读。

凭据 `status` 取值：`complete`（规划块全部核对通过且领取后描述复核一致）、`aborted-version-conflict`（来源版本/原点变化，拒绝拼接）、`incomplete`（传输、HTTP 或网格核对失败）。`coverage.missingCells` 逐项列出未取得网格点的索引与坐标，`notes` 用自然语言解释多取、出界、时间轴限制与失败原因；不做插值，也不提供地图展示。
