# 资料服务接口

资料源支持单段 HTTP Range，返回 Content-Range 和内容摘要 ETag。If-Match 可以限定本次范围读取的来源版本，版本不符返回 412，越界返回 416。该行为只负责传输，不替接收应用决定领域对象是否完整。

本地子集服务实际执行轴标签、包含式采样范围与四个网格单元的单次上限；更新后的描述和返回网格一并改变版本、原点。数量相同不证明网格相容。

本地网关把 WCS DescribeCoverage 与覆盖响应规范化为保留轴、网格和版本的 JSON；并不声称 JSON 是所有 WCS 服务的必选格式。能力表规定切片和裁切支持，网格上下界为包含式整数索引，物理范围与网格索引必须区别。

本地服务的资料入口为 `/wcs/describe/park-temp`。`fixtures/ordinary.json` 记录当前可预览的资料；`fixtures/transition.json` 保存资料源连续两个发布日期。调用 `POST /control` 并传入 `{"action":"advance"}` 推进发布日期，`inspect` 返回实际请求记录，`reset` 恢复本地源；控制入口不属于远端标准协议。来源分段、延迟和断连均可用场景条目的 `chunks`、`delayMs`、`disconnect` 配置，不需要依赖实际网络故障。

原件目录采用内容摘要寻址，接收凭据独立记录来源、媒体类型和预览结果。单份资料接收不表示来源范围已经读完，也不推断缺失资料的业务含义。
